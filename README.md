## 📂 Projects That Actually Shipped

### 🏦 [GenAI-Assisted Financial Reporting Pipeline — Allwyn Corporation](https://github.com/surthesh25/Converting-Oracle-Hyperion-Reports-to-Tableau-Using-Generative-AI-Coding-Assistants.git)
> Python · Databricks · Spark · Tableau · Star Schema · GenAI · REST API

Industry-partnered capstone with Allwyn Corporation. Built a GenAI-assisted pipeline that consolidated **133K+ financial records**, automated the entire Hyperion-to-Tableau migration workflow, and delivered **2 production-ready dashboards** with full validation and audit artifacts.

The hard part wasn't the pipeline — it was mapping Hyperion's financial logic into Tableau-compatible calculations without losing accuracy. Presented at GMU's DAEN 690 Capstone Seminar.

### 🚗 [Road Accident Severity Prediction](https://github.com/surthesh25/Road-Accident-Severity-Prediction.git) &nbsp;|&nbsp; [🚀 Live Demo](https://crashanalytics-ixuvy7gk9cy7z6c66fsw9h.streamlit.app/)
> Python · Scikit-learn · SHAP · LIME · SMOTE · Streamlit

**132K+ accident records across 10 countries.** Built severity prediction models and deployed a live Streamlit dashboard that makes the findings accessible to non-technical stakeholders — because a model nobody can use is just math.

- Used SHAP and LIME to explain *why* the model made each prediction
- Applied SMOTE to fix class imbalance before anyone asked
- The dashboard is live — go break it

### 💳 [Credit Card Cancellation Prediction](https://github.com/surthesh25)
> R · tidymodels · Random Forest · ROC-AUC

**95.7% accuracy. AUC 0.991.** Built on 4,627 U.S. bank customer records. Feature engineering surfaced low spend and transaction frequency as the dominant churn signals — gave the team something actionable, not just a model score.

---

### 🛣️ [Pavement Degradation Prediction — PySpark at Scale](https://github.com/surthesh25)
> PySpark · Databricks · Spark MLlib · AWS · Seaborn

**15 million FHWA records across 5 U.S. states.** Engineered scalable ETL/ELT pipelines on Databricks, enforced cloud data governance on AWS, and built Random Forest and Gradient Boosting models hitting **R² = 0.81** for pavement degradation prediction.

This one was about scale — making sure the pipeline didn't fall over at 15M rows.

---

### 🫁 [PM2.5 Exposure & Cardiovascular Mortality](https://github.com/surthesh25/PM2.5-Exposure-Cardiovascular-Mortality-Analysis-.git)
> Python · R (GIS) · SQL · Plotly

**2,132 U.S. counties. 20 years of data.** Applied regression modeling and R-based GIS mapping to uncover how air pollution exposure maps to cardiovascular mortality across socioeconomic lines. The kind of analysis where getting it wrong has real consequences.
